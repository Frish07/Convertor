FFmpeg WebAssembly

Convertor Web loads the upstream single-threaded @ffmpeg/core@0.12.10 from jsDelivr with integrity checks. This binary is distributed by the npm package provider under GPL-2.0-or-later. The JavaScript wrapper @ffmpeg/ffmpeg@0.12.15 is MIT licensed.

  • Upstream release for core 0.12.10 and wrapper 0.12.15
  • Corresponding upstream source and build scripts
  • Dockerfile with FFmpeg and codec library source revisions
