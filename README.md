# Convertor

Десктопный конвертер видео, изображений и аудио для Windows 10 и 11 (x64). Интерфейс написан на Python и Tkinter. FFmpeg обрабатывает медиа в отдельном процессе, а совместимые потоки приложение копирует без перекодирования.

## Запуск

1. Скачайте архив для Windows x64 из [Releases](https://github.com/Frish07/Convertor/releases/latest).
2. Распакуйте архив целиком и запустите `Convertor.exe`.
3. Если приложение предложит скачать FFmpeg, нажмите **Скачать FFmpeg**. Загрузка (~110 МБ) нужна один раз. Приложение проверяет SHA-256 архива и сохраняет движок в локальный профиль Windows. После этого файлы конвертируются офлайн.
4. Выберите вкладку, добавьте файлы, выберите формат результата и нажмите **Конвертировать**.

По умолчанию результат сохраняется рядом с исходным файлом. Папку можно изменить на каждой вкладке. При совпадении имени Convertor добавит номер, например `ролик (2).mp4`. Двойной щелчок по строке открывает готовый файл или показывает детали ошибки. Отмена прерывает текущую операцию и сохраняет результаты уже завершённых файлов.

## Форматы результата

| Вкладка | Выходные форматы | Примеры |
| --- | --- | --- |
| Видео | MP4, MKV, WebM, MOV и все аудиоформаты | MKV → MP4, MP4 → MP3 |
| Изображения | PNG, JPG, WebP, BMP, TIFF | WebP → PNG |
| Аудио | MP3, WAV, FLAC, M4A, OGG, Opus, AAC | OGG → MP3 |

Для видео используется первый видеопоток и первая аудиодорожка. При извлечении аудио сохраняется первая аудиодорожка. Вкладка изображений записывает один кадр.

Convertor использует установленный `ffmpeg` и `ffprobe` из PATH, из папки приложения или из её подпапки `ffmpeg/bin`. Встроенная кнопка скачивает [FFmpeg Essentials для Windows](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2) от Gyan Doshi (GPLv3). [Исходный код FFmpeg для этой сборки](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b).

## Запуск из исходников и проверка

Нужен Python 3.13 x64 с Tkinter и сборка FFmpeg с кодеками из FFmpeg Essentials.

```powershell
python main.py
python -m unittest discover -s tests -v
```

Интеграционные тесты генерируют небольшие медиафайлы и проверяют декодирование результатов, сохранение оригинала, отмену и обработку повреждённого файла.

## Сборка архива для Windows

```powershell
python -m pip install -r requirements-build.txt
.\scripts\build_windows.ps1
```

Архив появится в `dist`. Сборка скачивает тексты лицензий Tcl и OpenSSL для версий библиотек в выбранном Python.
